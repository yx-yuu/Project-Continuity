## 恢复入口

1. 每次只读取 [项目定义](project.md) 和 [当前状态](state.md)。
2. 跨会话、关键或跨阶段任务存在时读取 `checkpoint.md` 中的任务契约；文件不存在时不要创建空 checkpoint。
3. 只有需要理解仍然有效的关键取舍时才读取 [必要决策](decisions.md)。
4. 其他项目材料只有在下方“当前项目来源”登记且与任务相关时才读取。

## 文件职责

| 文件 | 只保存 |
|---|---|
| `project.md` | 当前研究定义、范围、术语和稳定约束 |
| `state.md` | 当前阶段、焦点、下一步和阻塞 |
| `decisions.md` | 缺失后可能导致重复犯错的最少决策理由 |
| `checkpoint.md` | 一个尚未结束任务的范围、完成条件、验证边界、影响对象和恢复状态 |

## 生命周期

新材料先作为候选；核验项目约束并处理受影响对象后，替换对应的当前信息。被替代内容应删除，只有复现、审计或合规确有需要时才移出默认上下文保存。具体领域流程按需加载，harness 不保存完整对话和任务历史。
