## Research Harness 项目控制协议

- harness 只维护当前项目定义、目录职责、稳定约束、当前状态和必要任务边界；不维护文件清单、文件快照或任务历史。
- 开始或恢复工作时，先读取 `agent-docs/project.md` 和 `state.md`；存在 `checkpoint.md` 时再读取当前任务契约。
- 同一 worktree 只允许一个活动写任务。若已有 checkpoint 与新写任务目标不同，先报告冲突，不得覆盖或混合两项任务。
- 关键、长程或跨阶段任务由 agent 直接创建并持续覆盖一个 `checkpoint.md`；小型局部任务不创建。
- agent 根据任务自行检查相关目录、Git 变化、代码、实验、结果和论文，不把自动扫描或模型推断当作项目事实。
- `project.md` 只记录稳定的目录级职责和影响关系；不登记数据集、实验产物或源码文件全集。
- 新结论通过约束、证据和完成条件核验后，直接替换对应当前信息，并检查相关目录和下游对象。
- 任务结束时更新 `state.md` 和必要的稳定约定，随后用可恢复方式删除 checkpoint；不保存任务 archive。
