# 当前项目控制协议

research-harness 是单个科研项目的轻量控制面。它维护当前项目定义、约束、状态、必要决策、证据关系、任务边界和变更影响；详细的文献、方法、实现、实验、分析与审稿步骤由按需 skill 执行，但必须服从项目控制面。

## 四个不变量

1. 默认恢复包只包含当前有效信息和当前任务契约。
2. 同一对象只有一个当前权威位置，新信息通过核验、影响传播和替换生效。
3. 任务的执行步骤可以变化，项目约束、证据门禁、范围和完成条件不能被绕过。
4. 无论项目持续多久，核心文件数量和默认恢复预算保持固定。

## 固定核心

| 文件 | 当前职责 | 禁止保存 |
|---|---|---|
| `AGENTS.md` | agent 共用的最短控制协议和恢复入口 | 具体科研流程、项目进展、实验数字 |
| `CLAUDE.md` | Claude Code 对 `AGENTS.md` 的 import 适配 | 项目事实、协议副本、任务状态 |
| `index.md` | 恢复路由、当前来源及其任务适用范围 | 自动候选全集、材料摘要副本 |
| `project.md` | 当前研究定义、项目级约束、术语和稳定边界 | 演变历史、临时任务策略 |
| `state.md` | 当前阶段、焦点、下一步、阻塞和证据门禁 | 完成日志、详细结果 |
| `decisions.md` | 忘记后可能重复犯错的最少理由 | 普通实现选择、完整讨论过程 |
| `checkpoint.md` | 一个任务的范围、完成条件、验证边界、影响对象与恢复状态 | 多版本 checkpoint、命令日志 |

`checkpoint.md` 是临时任务契约，不属于永久核心。小型局部任务不创建；关键、长程、跨阶段或需要跨会话恢复的任务才创建，并在完成同步后删除。

## 项目约束与任务流程

项目级研究边界、数据规则、实现不变量、证据门禁和外部要求由 `project.md` 或 `index.md` 登记的当前权威来源管理。具体任务 skill 决定执行方法，但不能修改或忽略这些约束；发现约束需要变化时，先将变化作为 candidate，由用户或可核验证据确认后替换权威来源。

## 证据升级与变更传播

代码、数据、运行产物和论文内容以各自当前源文件为准。扫描结果、compact 摘要、模型推断和任务输出都是 candidate。只有在核验任务完成条件、识别受影响对象并更新对应当前来源后，才能执行 `sync --accept` 将文件系统状态接受为新基线。

## 轻量预算

预算是 warning，不自动截断内容：

| 对象 | 默认预算 |
|---|---:|
| AGENTS 受管理区块 | 24 行 |
| CLAUDE 适配区块 | 8 行 |
| index | 120 行 |
| project | 180 行 |
| state | 120 行 |
| decisions | 200 行 |
| checkpoint | 120 行 |
| 默认恢复包 | 32,000 bytes |

超过预算时优先删除重复、历史、过程和已有权威来源的副本。不要通过拆成更多默认读取文件规避预算。
